# Contributing

`krwfolio` values small, auditable accounting changes over broad trading features.

Before opening a pull request:

```bash
pytest
ruff check .
```

Useful issue labels:

- `area:accounting`
- `area:fx`
- `area:rebalance`
- `area:attribution`
- `area:data`
- `area:cli`
- `type:bug`
- `type:feature`
- `type:docs`
- `type:test`
